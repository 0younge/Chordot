# 코드닷(Chordot)

코드 이름을 입력하면 기타에서 연주할 수 있는 여러 운지를 찾아주는 웹앱입니다. 구성음과 손가락 위치를 확인하고, 소리를 듣거나 마음에 드는 운지를 보관할 수 있습니다.

**[코드닷 사용하기](https://0younge.github.io/Chordot/)**

## 주요 기능

- **코드 검색** — 메이저·마이너·파워 코드, 6·7·9·11·13화음, dim·aug·sus·add·변화음·슬래시 코드 지원
- **운지표와 추천** — 줄별 음, 개방현·뮤트, 추천 손가락과 바레 표시
- **검색 조건** — 5·9·12·15프렛 범위, 바레 제외, 구성음 모두 포함, 손가락 벌림 조절
- **소리 듣기** — 코드 전체 또는 한 음씩 재생하고 중지
- **보관과 공유** — 운지 저장, 백업 내보내기·불러오기, 선택한 운지와 검색 조건을 담은 링크 복사
- **오프라인 사용** — 첫 접속에서 필요한 파일을 저장한 뒤 인터넷 없이 검색

HTML·CSS·JavaScript로 만들었으며, 운지 계산과 소리 합성을 브라우저에서 처리합니다. 별도 백엔드·데이터베이스·유료 API나 외부 실행 라이브러리가 필요하지 않습니다.

## 사용 방법

1. 코드 이름을 입력합니다. 예: `Cmaj7`, `F#m7b5`, `G7(b9)`, `D/F#`
2. 검색 조건을 조절하고 원하는 운지를 선택합니다.
3. 소리를 듣거나 보관함에 저장합니다. `링크` 버튼으로 같은 운지와 조건을 공유할 수 있습니다.

`CM7`·`C△7`·`Cmaj7`, `Bø`·`Bm7b5` 같은 별칭과 유니코드 샵·플랫도 인식합니다.

### 보관함과 백업

보관함은 현재 사이트의 브라우저 저장 공간에 최대 150개 운지를 저장합니다. 기기 간 자동 동기화는 없으며, 브라우저 데이터를 지우면 함께 사라집니다.

`내보내기`로 JSON 백업을 저장하고 다른 기기나 주소에서 `불러오기`로 가져올 수 있습니다. 불러오기는 기존 보관함에 중복 없이 합치며, 1MB 이하의 파일을 지원합니다. 사이트 주소를 옮기거나 브라우저 데이터를 지우기 전에 백업하세요.

### 오프라인과 업데이트

HTTPS 또는 localhost에서 처음 접속해 필요한 파일이 모두 저장된 뒤 오프라인으로 사용할 수 있습니다. 브라우저가 캐시를 정리하면 인터넷에 연결해 다시 방문해야 합니다.

새 버전은 화면의 적용 안내를 통해 사용할 수 있습니다. 적용할 때 현재 코드·운지·검색 조건을 유지합니다.

## 로컬 실행

Python 3이 설치된 환경에서:

```sh
git clone https://github.com/0younge/Chordot.git
cd Chordot
python3 -m http.server 4173 --directory dist
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 엽니다. 별도 패키지 설치나 빌드 과정은 없습니다.

## 개발과 배포

검증에는 Node.js 24를 사용합니다. 저장소 루트에서 실행하세요.

```sh
node scripts/update-sw.js --check
node --test tests/*.test.js
```

코드 해석·운지 조건, 보관함·백업·링크 복원, 오디오 재생 취소, 오프라인 캐시·업데이트·복구 동작을 검사합니다. 자동 검사는 실제 기타 연주와 모든 브라우저에서의 동작 확인을 대신하지 않습니다.

`dist`의 실행 파일을 수정했다면 검증 전에 아래 명령으로 오프라인 파일 해시를 갱신하세요. README·문서·테스트만 수정한 경우에는 필요하지 않습니다.

```sh
node scripts/update-sw.js
```

[GitHub Actions](.github/workflows/pages.yml)가 `main` 브랜치 변경 시 해시와 테스트를 확인한 뒤 `dist` 폴더를 GitHub Pages에 배포합니다. Pages의 배포 소스는 **GitHub Actions**를 사용합니다. 다른 정적 호스팅에서도 `dist` 폴더의 내용을 그대로 배포할 수 있습니다.

## 지원 범위와 제한

- 표준 튜닝 **E2 A2 D3 G3 B3 E4**, 카포 없음 기준입니다. 대체 튜닝·`alt`·폴리코드는 지원하지 않습니다.
- 최대 15프렛, 손가락 네 개, 바레 하나 범위에서 탐색합니다. 엄지 운지와 여러 바레를 포함한 모든 연주 방법을 다루지는 않습니다.
- 코드에 따라 완전5도와 일부 확장음을 생략할 수 있으며, 생략한 음은 화면에 표시합니다. `구성음 모두 포함`을 켜면 생략하지 않습니다.
- 9·11·13도는 음높이 종류로 계산하므로 반드시 근음보다 해당 간격만큼 높은 옥타브에 배치되지는 않습니다. 모든 구성음을 담을 수 없는 화음은 생략을 허용해야 결과가 나올 수 있습니다.
- 난이도와 손가락 번호는 추천입니다. 손 크기와 연주 습관에 맞는지는 실제 기타에서 확인하세요.
- 재생음은 Web Audio API로 합성한 음색입니다. 실제 기타 녹음은 사용하지 않습니다.
