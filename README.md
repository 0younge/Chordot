# 코드닷(Chordot) · 기타 코드 찾기

낯선 코드를 기타에서 연주할 수 있는 여러 모양으로 보여 주는 정적 웹앱입니다. 별도 백엔드, 데이터베이스, 유료 API 없이 브라우저에서 계산하며 시스템 글꼴을 사용합니다.

**[코드닷 사용하기](https://0younge.github.io/Chordot/)** · [GitHub 저장소](https://github.com/0younge/Chordot)

## 실행

`dist/index.html`을 브라우저에서 바로 열어 검색과 소리 재생을 사용할 수 있습니다. 파일 주소에서 브라우저 저장 기능을 제한하는 환경에서는 보관함 저장이 실패할 수 있습니다. 일반적인 사용과 검증에는 아래 로컬 서버 또는 HTTPS 배포 주소를 권합니다.

로컬 서버 예시:

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://localhost:4173`을 엽니다.

오프라인 캐시는 HTTPS 또는 localhost처럼 서비스 워커를 사용할 수 있는 환경에서 동작합니다. 파일을 직접 열면 운지 계산은 현재 화면에서 수행하고, 웹 주소에서는 별도 작업 스레드를 사용합니다. 정확한 운지를 담은 링크 복사는 웹 주소에서 사용할 수 있습니다.

## 무료 정적 호스팅으로 옮기기

### GitHub Pages

현재 공개 주소는 **https://0younge.github.io/Chordot/** 입니다. `.github/workflows/pages.yml`에서 `main` 브랜치 변경 시 오프라인 파일 해시와 전체 테스트를 확인한 뒤 `dist` 폴더만 GitHub Pages에 배포합니다. 저장소의 **Settings → Pages → Source**는 **GitHub Actions**를 사용합니다. 정기 실행 예약은 없습니다.

화면·실행 파일을 수정했다면 `node scripts/update-sw.js`로 오프라인 파일 목록을 갱신한 뒤 커밋하세요. README나 테스트만 바꿀 때는 해시 갱신이 필요하지 않습니다.

이전 사이트의 보관함은 새 주소로 자동 이동하지 않습니다. 이전 주소에서 **내보내기**로 저장한 백업 파일을 새 주소의 **불러오기**에서 선택하세요.

### 다른 정적 호스팅

Cloudflare Pages의 정적 파일 업로드에 `dist` 폴더의 내용을 올리면 됩니다. GitHub Pages를 사용하는 경우에도 같은 정적 파일을 배포하면 됩니다. 별도 빌드 명령이나 환경 변수는 필요하지 않습니다. 무료 기본 주소를 사용할 수 있으며, 호스팅 정책은 배포 시 공식 문서에서 확인하세요.

이 프로젝트의 Sites 배포 정보는 `.openai/hosting.json`에 있습니다. 앱의 기능에는 Sites 전용 서버 API가 없습니다. 배포된 사이트의 접근 권한은 운지 링크를 복사해도 바뀌지 않습니다.

## 기능

- 메이저·마이너·파워·6·7·9·11·13 코드, maj/dim/aug/sus/add/변화음, 슬래시 코드
- 코드 별칭 정규화: CM7 / C△7 / Cmaj7, Bø / Bm7b5, 유니코드 샵·플랫
- 구성음, 생략음, 최저음, 줄별 실제 음 표시
- 5/9/12/15프렛 범위, 바레 제외, 모든 구성음 포함, 손가락 벌림 조건
- 익숙한 기본 운지, 근음 베이스, 충분히 울리는 줄을 고려한 추천 순위
- 추천 손가락과 단일 바레를 포함한 SVG 운지표. 모바일에서는 주 운지표를 크게 표시
- 합성 현악기 소리와 한 음씩 재생, 재생 중지. 코드·운지·화면을 바꾸면 이전 재생 취소
- 선택한 운지와 검색 조건을 함께 복원하는 링크, 브라우저 뒤로가기·앞으로가기 지원
- 현재 브라우저에 운지 보관, 파일로 내보내기·불러오기, 삭제 직후 되돌리기
- 오류를 설명하는 검색 결과와 키보드 조작, 화면 읽기 프로그램을 위한 상태 안내
- 설치된 정적 파일 묶음을 이용한 오프라인 사용과 연결 상태 안내
- 새 버전이 준비되면 적용 안내. 사용자가 적용하면 현재 코드·운지·조건을 주소에 담아 새로 열기

## 보관함과 링크

보관함은 최대 150개의 운지를 저장합니다. 저장한 프렛을 다시 검증하고 그대로 열며, 새 추천 순위에 없다는 이유로 다른 모양을 대신 표시하지 않습니다. 검증에 맞지 않는 이전 운지는 원래 프렛과 이유를 보여 줍니다.

`내보내기`로 JSON 백업 파일을 내려받아 다른 기기에서 `불러오기`로 가져올 수 있습니다. 불러올 파일은 1MB 이하여야 하며, 기존 보관함에 중복 없이 합칩니다. 형식이 잘못되거나 최대 개수를 넘으면 기존 내용을 덮어쓰지 않습니다. 기기 간 자동 동기화는 없으며, 브라우저 데이터를 삭제하기 전에는 파일로 백업하세요.

저장할 때 최신 보관함을 읽고, 지원되는 환경에서는 Web Locks로 여러 탭의 동시 쓰기를 조정합니다. 저장 공간에 접근하지 못하면 오류를 알립니다. 읽은 원문이 손상된 경우에는 새 저장을 멈추고 원문을 복구용 파일로 내보낼 수 있습니다.

상세 운지의 `링크` 버튼은 코드 이름, 선택한 여섯 줄의 프렛, 검색 조건을 주소에 담습니다. 링크를 다시 열면 같은 운지를 검증해 표시합니다. 코드나 프렛 정보가 잘못된 주소는 오류를 보여 주며 다른 코드로 조용히 바꾸지 않습니다.

## 정확성 기준과 제한

- 각 줄은 표준 튜닝 E2 A2 D3 G3 B3 E4, 카포 없음 기준입니다.
- 누른 음이 허용된 구성음인지, 필수 음이 포함되는지, 지정 베이스가 실제 최저음인지 확인합니다.
- 완전5도 및 일부 낮은 확장음만 생략할 수 있고, 생략한 음은 화면에 표시합니다. 근음·성격을 결정하는 음·변화음은 유지합니다. ‘구성음 모두 포함’을 켜면 생략하지 않습니다.
- 확장음은 음높이 종류 기준으로 계산하므로 9·11·13이 반드시 근음보다 그만큼 높은 옥타브에 배치되는 것은 아닙니다.
- 탐색 범위는 최대 15프렛, 손가락은 최대 네 개, 바레는 최대 하나입니다. 바레가 개방현·뮤트 줄·더 낮은 프렛을 가로지르는 모양은 제외합니다. 엄지 운지나 여러 바레, 모든 가능한 특수 운지를 다루지 않습니다.
- 난이도와 손가락 번호는 휴리스틱 제안입니다. 실제 손 크기와 관절 가동 범위까지 보장하지 않으므로 실제 기타로 확인해야 합니다.
- 일부 익숙한 운지에는 코드 전환을 고려한 손가락 번호를 사용합니다. 외부 운지 데이터베이스나 이미지의 복제는 없습니다.
- `alt`, 폴리코드, 임의의 튜닝은 지원하지 않습니다. 알 수 없는 입력을 다른 코드로 추측하지 않습니다.
- 모든 음을 동시에 담을 수 없는 13화음은 생략 옵션을 이용해야 합니다.
- 소리는 브라우저에서 합성한 현악기 음색이며 실제 기타 녹음이 아닙니다.
- 보관함은 해당 브라우저에만 저장되며 브라우저 데이터를 삭제하면 함께 사라집니다.

## 오프라인과 업데이트

처음 접속할 때 인터넷 연결이 필요하며, 필요한 파일이 모두 검증되고 저장된 뒤 오프라인에서 사용할 수 있습니다. 브라우저가 저장 공간을 정리하거나 캐시를 지우면 연결 후 다시 방문해야 합니다.

서비스 워커는 이 앱의 정적 파일만 다루고 로그인 페이지·외부 주소·다른 경로를 가로채지 않습니다. 새 버전은 기존 화면을 강제로 새로고침하지 않고 적용을 기다립니다. 같은 도메인의 여러 경로에 배포해도 캐시를 구분합니다.

정적 파일을 수정해 배포할 때는 `node scripts/update-sw.js`를 실행해 파일별 SHA-256과 묶음 식별자를 갱신하세요. `node scripts/update-sw.js --check`로 모든 파일과 일치하는지 검증할 수 있습니다. 서비스 워커는 이 해시와 일치하는 파일만 설치·복구하므로 이전 버전 화면에 새 버전 파일을 섞지 않습니다. 배포 서버는 파일 본문을 자동으로 수정하거나 스크립트를 삽입하지 않아야 합니다.

앱에 필요한 파일이 없어 안전하게 열 수 없으면 외부 파일에 의존하지 않는 복구 화면을 표시합니다. ‘파일 다시 준비하기’를 누르면 준비된 새 버전을 적용하거나 온라인으로 다시 준비한 뒤 같은 주소를 엽니다. 실패하면 재시도할 수 있습니다. 최신 버전 적용 시 운지 링크를 통해 현재 선택을 이어서 열고, 보관함은 기존 브라우저 저장 공간에 유지합니다.

53개 운지의 줄·프렛 음높이를 별도로 정리한 화음 공식과 대조해 코드 밖의 음이 없는지, 필수음과 슬래시 코드의 최저음이 맞는지 확인했습니다. 현재 프로그램의 기본 검사 조건에서도 **53개 모두 유효**했고, 지정한 손가락 번호 4개도 누르는 줄과 일치했습니다. 이 검사는 음악적 일치에 대한 확인이며 출처 증명이나 실제 손의 연주 편의성 검증은 아닙니다.
